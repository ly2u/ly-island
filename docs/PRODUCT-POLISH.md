# 日常写作、阅读与维护

这轮围绕现有站点补齐使用流程，不改变内容格式、账号体系、成长规则或部署入口。

## 写作与阅读

总览的「随手速记」直接打开简洁笔记编辑器。标题可留空，明确保存草稿或发布时从
正文第一条有效文字生成；输入仍由原来的浏览器暂存与服务器私有编辑草稿保护。
「继续完整编辑」与「简洁速记」只切换视图，不另建草稿、不清空正文、不自动发布。
正文图片、图片库及粘贴上传沿用原来的存储和隐私规则。

编辑器右侧的实时预览继续按源码位置跟随。上方「预览」打开完整访客视角，显示
标题、分类、摘要、封面、目录、表格、公式和阅读排版。请求必须经过管理员会话、
来源和 CSRF 检查；不落盘、不改变公开原文，也不产生可分享的草稿地址。
预览不显示分享、永久链接或阅读书签。

岛内阅读和独立 `/notes/<slug>` 页共用 `reader-view.mjs`、`reader-client.mjs` 与
`reader.css`。岛内仍对服务端正文执行浏览器白名单过滤。独立页保留服务器直接
输出的正文、目录锚点、canonical、Open Graph 和 Twitter 信息，关闭 JavaScript
也能阅读。它不加载 3D 场景。字号和阅读位置使用原来的浏览器存储，与岛内共用；
有指定锚点时优先跳到锚点。分享复制独立文章地址，不复制岛内 hash。

## 布置小岛

岛屿编辑支持最近 30 步布置撤销与重做：建筑、信箱、树木位置、阶段、光照与岸边
摆件。重置默认位置算一步。新修改会清除重做分支。保存或重新载入后重新建立基线。
撤销仅恢复这些场景字段，不覆盖正在填写的岛名、建筑名称、介绍与精选内容。

「对照已保存布置」临时显示上次保存的场景，禁用移动、阶段、光照、摆件、扩岛确认
和保存。结束对照后回到原来的未保存布置与视角。它不会替换存档。
聚焦场景时 Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做；正文输入框仍使用
浏览器自身的文字撤销。没有 WebGL 时文字设置与阶段/光照历史仍可操作。

## 后台维护摘要

总览显示当前发布、最近一次**通过临时恢复检查**的本地备份、图片用量与磁盘余量。
缺少摘要、格式异常或超过 48 小时没有成功备份时显示待检查，最近失败晚于成功时
显示提醒。图片和磁盘数字按刷新时读取，不是持续监控。

数据流是：现有 root 发布/备份脚本 → 过滤后的 JSON → 现有数据卷 → 登录后的只读
`GET /api/admin/site-status`。没有 Docker socket、新端口、宿主机操作接口或新定时任务。
应用无法通过这个接口运行备份、改 SSH、启停服务或读取环境文件。

宿主机保留 `/opt/ly-stack/status/backup-receipt.json`，root 目录 0700、文件 0600；
应用只读 `/srv/ly-data/sites/site-status.json`，原子替换、0600、属主与数据目录一致。
摘要只含发布编号/提交/时间、备份文件名/结果时间。服务端再次白名单过滤，不接受
完整路径、自由文本日志、环境变量、口令或令牌。缺失文件不会影响写作与阅读。

### 安装运维配套文件

发布器仅提示运维脚本差异，不自动安装。首次使用本轮维护摘要时，在完成标签预检查
后、正式发布前，从同一个已审查标签源码安装这两个文件。先保留当前版本：

```bash
# R 指向已合并、已核对标签的干净检出目录。
R=/path/to/clean/checkout
saved=/opt/ly-stack/rollback/before-maintenance-summary-$(date -u +%Y%m%dT%H%M%SZ)
install -d -m 0700 "$saved"
for file in backup.sh site-status.py; do
  if test -f "/opt/ly-stack/scripts/$file"; then
    cp -p "/opt/ly-stack/scripts/$file" "$saved/$file"
  fi
  install -m 0700 "$R/scripts/$file" "/opt/ly-stack/scripts/$file"
done
```

原有备份 timer 不变。`backup.sh` 只在解包与内容/发布产物校验通过后记录成功；
进入备份恢复 trap 后的失败记录失败状态，并保留上次成功时间。初始化前的失败
可能没有新回执，所以仍应检查 systemd 日志与备份目录，不能仅凭卡片断言一切正常。

发布或手动回滚完成后刷新发布信息；辅助摘要失败只提示，不推翻已通过检查的发布。
需要重新生成派生文件时：

```bash
python3 /opt/ly-stack/scripts/site-status.py refresh
```

这条命令只重读已有回执，不把某个文件或某次未验收备份标成成功。
摘要不是备份本身；备份与恢复步骤见 [发布与回滚](RELEASE.md)。

## 验证与边界

`check-product-polish.mjs` 检查共用阅读、元数据转义、预览认证/CSRF/来源与无写入、
长中文正文、速记标题、布置历史、维护摘要异常与未知字段过滤。
`scripts/check-site-status.py` 检查宿主机回执、权限、失败保留与发布信息刷新。
现有全部网站、岛屿构建、发布与恢复检查继续运行。

浏览器复现见 [tools/browser](../tools/browser/README.md)。使用合成账号、合成文章、
临时数据与本地服务，分别检查 Chromium、Firefox、WebKit，包括 390/320px 布局、
关闭 JavaScript 阅读、原生 MathML、表格、分享、共用书签、速记自动草稿、私密图片、
完整预览及布置历史。Chromium 还实际拖动书屋、信箱和树木并逐个撤销/重做。
Firefox 无 WebGL 的测试环境验收降级，不把它记作 3D 通过。

这些是桌面自动化浏览器引擎验收。真实手机键盘/中文输入、触摸手感、GPU、耗电及
Safari 应用本身仍需实机验证；线上验收只作只读检查，不新建测试文章、不登录真实
账号、不发送模型或 Civil 请求。
