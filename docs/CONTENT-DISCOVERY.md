# 建筑提示、精选与继续阅读

## 日常维护

打开后台 → 岛屿。书屋、工程展馆、工坊的名称与介绍下面，各有两个精选选择框。
选择已公开的记录，再点「保存并展示」，不需要重新构建网站。
两项留空时，空间自动展示最近更新的公开内容；只选一项就只推荐这一项。

- 书屋可选笔记、博客。
- 工程展馆可选项目及工程手记。
- 工坊可选探索类笔记、博客，原有 CivilFlow、七嘴工具入口仍在最前面。

列表只显示符合该空间范围的公开内容。每个空间最多两条，不能重复。
精选转为草稿、进入回收站或移出该空间后，公众接口会过滤其标识；没有可用精选时
改用最近的公开记录。后台保留原选择并提示下线，方便以后重新发布或换一条。
保存其他岛屿设置不会因旧精选下线而被阻止。保存仍检查登录、来源、CSRF 和版本冲突。

## 访客体验

建筑保留简短的名称标签和悬停高亮，不再额外弹出内容卡片，避免遮住岛屿。
标签可点击或用键盘聚焦后按 Enter，模型也可以直接点击，进入原有阅读空间。
公开数量、精选与最近记录放在点击后的空间和阅读模式入口，不在岛上悬停时展开。

每个空间顶部展示精选或最近记录，手机也能直接打开。阅读模式入口显示该空间的
公开数量与推荐标题。读完文章后，除原有系列和项目导航外，还会根据公开的专题、
标签和分类给出相关记录；进入另一类内容时使用合适的空间。

首页成长卡和阅读模式里新增「继续上次阅读」。它使用原有浏览器书签，显示当前
公开文章的标题，点开后恢复位置。已读完、零进度以及已经下线的记录不会作为待续显示。
「清除本机记录」只清除阅读书签，保留阅读模式和其他设置。

书签最多保存 40 条，只包含文章标识、位置、时间和所在空间，不向服务器上传。
不同设备、无痕窗口和清除浏览器数据后的记录不会自动同步。存储不可用时仍可正常阅读。

## 数据与回退

精选保存在 `island.json` 的 `buildings.<id>.featuredSlugs`，每项最多两个标识。
字段可省略；旧数据只在读取时补空值，不因升级重写或迁移原文件。
公开投影与后台原配置分开，草稿和回收站标识不经公众岛屿接口返回。
现有文章、图片、场景布局、信箱、成长规则和发布流程不改变。

旧版本可以读取这份岛屿文件，但会忽略新字段；用旧版后台重新保存岛屿会丢弃精选选择。
因此回退后若还要保留这些选择，应在升级回来后再编辑，或从备份取回对应配置。
回退代码不会恢复或删除文章。服务端备份仍不包含浏览器书签。

## 验证入口

Node 24，在 `apps/rqly-sites` 执行 `node scripts/check-discovery.mjs`。
17 组检查涵盖共享范围、排序/回退、私密内容过滤、字段限制、旧文件不重写、
版本冲突、真实 HTTP 权限/CSRF/来源检查、撤回安全、本机进度及相关内容排序。

全部网站检查仍按 `CONTRIBUTING.md` 执行；岛屿运行 `npm run test:scene` 和
`npm run build`。隔离 Chromium 使用合成站主、文章和数据，检查实际选择/保存/重载、
建筑入口、HTML 文本转义、正文和位置恢复、相关项目跳转、阅读模式不下载场景、清除记录、
390/320px 布局，以及精选撤回后的公众回退与后台提示。没有向线上写测试内容。
