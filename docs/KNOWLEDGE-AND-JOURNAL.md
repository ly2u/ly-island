# 知识书架与岛主博客

站主的定义是：**笔记是整理后的知识与资料，博客是个人想法、近况和随笔。**
不根据篇幅自动改类型。草稿/已发布仍是状态。现有文章的类型、正文与独立 URL 不迁移。

## 书屋的四层入口

分类书架 → 一本分类书 → 这本书的笔记列表 → 笔记正文。

- 后台「内容 → 分类与系列」创建 **专题（笔记分类）**，写笔记时在「笔记分类 / 专题」勾选。
- 公开笔记引用的分类才出现在公众书架，只有草稿引用的分类不会泄露名字。
- 每个分类封面展示分类名、介绍与笔记数量，不把每篇笔记画成一本书。
- 支持多个分类：同一篇笔记可以出现在不同的分类书中，存储与网址仍只有一份。
- 没有自定义分类的既有笔记仍有工程、探索或「待分类」入口，不会被藏起来。
- 分类用已有稳定 ID：改名字后书的链接不变。停用仍保留已有归属；引用中的分类不能删除。
- 分类书内的搜索限定于该分类的公开笔记；全岛搜索仍可跨类型查找。

SSR `/notes` 显示分类封面，`/notes?book=<分类ID>` 显示列表，关掉 JS 也可以逐层进入。
岛内使用 `room=library&book=<分类ID>`；打开正文、返回目录及浏览器前进后退都保留书的上下文。

## 岛主空间

岛主空间中「认识岛主」和「博客与近况」是两个独立标签，不把博客列表堆在介绍正文后面。
博客另有可直接访问和分享的 `/blog`，首页有原生入口，岛内用 `room=blog`，对应岛主建筑对焦。
不新增或搬动场景建筑。博客是时间动态与简洁正文，知识笔记保留完整目录与阅读书签。

博客、笔记的独立正文继续使用 `/notes/<slug>`，既有分享和搜索引擎地址保留。
旧 `room=library&article=<博客slug>` 在读取公开内容后转到博客阅读；不会根据猜测公开私有内容。
旧 `/notes?kind=blog` 兼容，规范地址为 `/blog`。全岛搜索、RSS、项目关联和相关记录仍可到达所有公开内容。

## 后台与兼容性

笔记默认完整编辑，并展开归属字段，方便先选分类；博客支持「随笔速写」和自动标题。
既有内容不做批量类型互换。若以前按旧定义创建了笔记/博客，可在编辑器改类型，再明确更新发布。
分类书复用 organization.topics，没有新增数据库或必填存储字段。旧书屋视图枚举仍可读取，
展示时兼容为分类书架；后台可选书架或紧凑分类目录。旧书屋的文章精选保留在配置中，
书屋先展示分类封面，管理员在「分类与系列」管理这些书。

只改应用和静态资源，通过 VPS 的既有标签发布流程上线，不部署 Cloudflare。
验证包含分类内搜索、私密分类隔离、分类改名后的稳定链接、无 JS 入口链路、
岛内书籍/笔记/博客导航、旧 hash、浏览器历史、编辑草稿及手机布局。验收不向线上写内容或发送 AI/Civil 请求。

回退兼容：书架样式仍使用原有 reading.libraryView 枚举；all 表示分类书架，notes 表示
紧凑分类目录，旧 blogs 值可读取并以书架展示。不写入旧版本不认识的新枚举值。
