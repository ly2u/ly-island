# 0002 产品方向：岛屿为首页，浏览器后台写作，功能暂不删减

- **状态：** 已采纳
- **日期：** 2026-10-07

## 决定

站主确定：

- 三维浮空岛继续作为 rqly.com 首页；
- 文章、笔记、项目继续通过浏览器后台维护，不改为在 Git 中写 Markdown；
- 现有功能暂不删减，包括七嘴、信箱、成长积分、个人 AI；
- 暂不考虑 CivilFlow 相关改动。CivilFlow V2 浏览器调用同源 `/api/compile`，由服务端校验并编译，导出 Civil 表和请求清单给已有执行器。编译及导出不连接 Civil，本次不改变执行端连接方式，也不发送真实写入或分析请求。

## 对其他决策的约束

- 控制维护成本的手段是分层、集中定义和自动约束（[0003](0003-layering-by-lifespan.md)、[0004](0004-single-source-data-schema.md)、[0009](0009-architecture-budgets.md)），而不是删减功能。
- 任何改动不得改变上述产品形态，除非站主另行决定。
