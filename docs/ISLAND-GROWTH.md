# 成长明细与扩岛预览

公众首页点击「成长足迹」，或在阅读模式点击「看看小岛如何成长」，可查看当前积分、
来源明细、实际保存的阶段、建筑变化和最近公开记录。只看明细不会加载 3D 模块。

规则沿用现有版本：公开笔记 1 点，博客 3 点，项目 5 点；完成项目另加 10 点，
因此一个完成项目总共 15 点。编辑同一条记录不重复加分，草稿和回收站不计入。
扩岛目标可在后台调整。已确认的解锁会保留，即使撤回内容后当前积分下降。
仍只有萌芽与扩展两个正式阶段，没有新增单建筑等级或历史积分台账。

## 预览与正式扩岛

「在 3D 岛上预览扩岛」会展示现有扩展阶段：书屋三层、展馆移至副岛并加到两层、
工坊两层，连接桥出现。预览使用各阶段已有的布局和同一个 WebGL 场景，
不修改岛屿对象、不发送保存请求，不解锁阶段，也不改动浏览器保存的阅读模式。

页面上方会持续标明预览状态。点击「回到实际小岛」或在岛上按 Escape，
恢复原外观、旋转角度和缩放。阅读空间打开时，第一次 Escape 先关闭阅读，
再按一次才退出预览。切换到阅读模式也会结束预览。
从阅读模式进入预览，退出时会返回阅读模式。

关闭正在加载的预览窗口会取消后续进入预览的动作；WebGL 不可用时仍可看明细，
按钮恢复可用。已有扩展小岛不会再进入“未来外观”预览。

后台「岛屿」增加积分明细和「只看 3D 扩岛效果」链接，在新窗口打开公众预览。
`/?preview=growth` 仅表示本次浏览器预览；退出时清理这个参数，其他查询参数和
当前页面地址保留。这个链接不会更改后台表单或保存设置。

正式扩岛仍走原有流程：后台达标后确认扩岛，再「保存并展示」。认证、来源、CSRF、
版本冲突与服务端积分检查保持原样；把预览参数或 `unlocked=true` 放进请求不能跳过检查。

## 数据边界

没有存档字段、运行文件、数据库或依赖变化。旧 `island.json` 原样读取。
后端与首页共用 `public/rqly/growth-core.mjs`，保持原有积分接口字段和计算结果。
足迹是当前公开记录的摘要，使用文章自身日期与公开列表顺序，不伪造历史解锁日期；
撤回后不再展示。私密草稿、信件和账号信息不进入成长面板。

## 验证

Node 24：网站目录执行 `node scripts/check-growth.mjs`，12 组检查涵盖共享计算、奖励、
门槛边界、解锁保留、公开投影、GET 无写入、未达标拒绝及后台预览链接。
岛屿的 `npm run test:scene` 增加视角捕获/恢复测试。

隔离 Chromium 使用合成站主、文章和数据，在 1280/390/320px 检查明细、隐私、
3D 预览、预览期间阅读、Escape 和原视角恢复、单一渲染器、零保存请求；另检查
阅读模式按需加载、取消迟到的导入、WebGL 失败及重试按钮、后台链接，以及已有扩岛的页面。
场景、目录、信箱和树木拖动等原功能沿用既有回归检查。线上只作只读验收。

后台布置的撤销、重做和保存前对照见 [日常写作、阅读与维护](PRODUCT-POLISH.md#布置小岛)。
