# 概念与定位

- **状态：** 第 0 阶段草案，待站主确认
- **日期：** 2026-10-13

## 一句话

一座自己托管、有邻里温度、帮你坚持记录的个人小岛。默认可以免费部署在 Cloudflare 上，几分钟就能有岛。

## 要解决的问题

| 问题 | 现状 | 这里的做法 |
|---|---|---|
| 记录很难坚持 | 博客写几篇就停。写了没人看，也看不到自己积累了什么 | 每次记录都让岛长出新东西，积累看得见；邻居和漂流瓶带来少量但真实的回应 |
| 内容不属于自己 | 朋友圈导不出来；X 的算法决定谁能看到；平台关停或封号，记录跟着消失 | 内容是自己仓库里的标准 Markdown，域名是自己的，可以随时搬走 |
| 社交要么太熟，要么太吵 | 朋友圈全是熟人，发什么都像在表演；X 是公共广场，拼的是流量 | 介于两者之间：一小圈邻居，加上漂流瓶带来的偶遇。不显示点赞数排行，不做算法推荐 |
| 个人资料散落各处，AI 用不上 | 想让 AI 了解你，得一次次复制粘贴 | 记录是结构化的，接口是公开的。你自己的 AI 管家可以读，也可以起草，但由你确认 |

## 和现有平台比

| | 朋友圈 | X | 独立博客 | 这里 |
|---|---|---|---|---|
| 内容归谁 | 平台 | 平台 | 自己 | 自己 |
| 谁能看到 | 好友 | 算法决定 | 搜索来的人 | 邻居、订阅者、捡到瓶子的人 |
| 互动 | 点赞、评论 | 点赞、转发、回复 | 评论区（常常关掉） | 拜访、留言、浇水、漂流瓶 |
| 坚持的动力 | 熟人反馈 | 流量 | 几乎没有 | 岛在长，加上邻居的回应 |
| 换地方 | 不能 | 不能 | 能 | 能，身份跟着走 |
| 成本 | 免费 | 免费 | 主机或免费托管 | 默认免费 |

**客观判断：** 这不会成为大众产品。它的网络效应弱，第一批用户只会是懂一点技术的人。它的机会在小众但真实的群体：

- 中文独立博客圈本来就有友链文化，也有"开往"（博客之间随机跳转的友链接力）、"十年之约"（承诺把博客写满十年的联盟）这类项目；
- 国外有 IndieWeb、webring、Neocities 这些例子。

这些都说明有人需要"自己的站、但不孤单"。这里多做的一步，是把社交和"坚持记录"放在同一个循环里。

## 核心循环

```
记录 ──► 岛长出新东西 ──► 邻居在动态里看到 / 漂流瓶被陌生人捡到
 ▲                                          │
 │                                          ▼
再记录 ◄── 回访、回信 ◄── 收到通知：谁来了、谁留言、瓶子被谁捡到
```

所有功能都要回答一个问题：它让这个循环更顺，还是更累？

## 原则

1. **自由。** 没有中心账号，没有平台审核。过滤和屏蔽是岛主自己的工具，不是平台的权力。
2. **数据归自己。** 内容是标准 Markdown，互动数据可以导出，搬家不丢身份。
3. **协议优先。** 岛与岛之间靠公开的数据格式互通，不依赖某一台服务器。任何人都可以写自己的实现。
4. **不执行邻居的代码。** 别人的岛只作为数据读取，用自己的主题来画。
5. **便宜、轻。** 默认用 Cloudflare 免费档；首屏有预算；低端手机也能用。
6. **AI 起草，人确认。** AI 可以读、整理、提醒、起草；发布和一切对外的社交动作都必须由人确认。
7. **规则开源。** 成长、积分、通知策略都是代码里的默认值，谁都可以改。
8. **不上链。** 借鉴去中心化的思路：自有身份、签名、可迁移。不用区块链、代币、NFT 或钱包。

## 不做什么

- 中心化账号、平台审核、算法推荐、全局排行榜、广告；
- 即时聊天：留言就够了；
- 移动 App：先把手机网页做好；
- 替别人托管岛：灯塔只做索引，不存内容。

## 第一年的成功标准

- 50 座活跃的岛。活跃指最近 30 天有记录。
- 活跃的岛里，一半以上每月记录 4 次以上。
- 新人从点部署按钮到岛上线，不超过 10 分钟。
- 至少出现一个不是我们写的主题或实现。

## 风险

| 风险 | 应对 |
|---|---|
| 冷启动：没人就没有邻居 | 先从有友链传统的博客圈开始；纯静态的博客也能当邻居（见[部署](deployment.md#三种参与方式)）；能订阅普通 RSS |
| 滥用：不审核就会有垃圾留言 | 岛对岛的动作必须带签名；接收策略、屏蔽、限速、人机验证都由岛主自己设置 |
| 免费档条款变化 | 协议和静态页面不依赖平台；Worker 代码按可迁移的方式写（见[部署](deployment.md#不被平台绑死)） |
| 协议做大了，没人愿意实现 | v0 保持最小；不认识的字段和类型直接忽略 |
| 成长系统变成负担 | 按周计连续；不惩罚；已解锁的外观不收回；没有全局排行（见[扩展接口](extensions.md#成长规则)） |
