# 首次访问、轻量导览与加载兜底

保留浮空岛作为首页，补齐初次到访者能认识岛主、找到内容和选择轻量模式的流程。
本轮不新增数据服务、统计脚本、评论服务或运行数据字段。

## 对外部建议的核对

| 建议 | 当前证据与处理 |
| --- | --- |
| 首屏说明身份 | 采纳。身份文字来自现有关于页：桥梁工程与数字工具实践，点击可认识岛主；保留原主视觉文案和站主保存的介绍。 |
| 空岛要有出口 | 岛主建筑、关于页、工具入口及公开文章已经存在。补充真正为空的空间引导，不预置假文章，不增加遮挡建筑的告示牌。 |
| 移动端降级 | 已有像素预算、低分辨率阴影、慢帧降画质、阅读时停止绘制。本轮增加触摸提示、默认暂停漂浮、条件式轻量导览与偏好保留。 |
| 文章 SSR | 已有 `/notes/<slug>` 服务端正文、canonical/OG、站点地图与无 JS 阅读；岛内分享复制独立文章链接。保持并回归。 |
| 加载进度 | 改为真实的配置/场景资源/首帧阶段，并允许立即跳过；没有总字节进度时不伪造百分比。 |
| WebGL 失败兜底 | 现有阅读入口继续使用，增加无需 WebGL 的可点击 SVG 示意导览。 |
| Umami | 暂缓。官方自托管需要 PostgreSQL 和独立服务，增加当前站点的维护范围；本轮没有安装或开启追踪。 |
| Giscus | 暂缓。现有公开留言板和私信保留；Giscus 需要公开仓库 Discussions、安装应用及访客 GitHub 授权，先保留现有反馈路径。 |
| 隐私与备案尾部 | 信箱已有审核/邮箱用途/删除说明。本轮补独立 `/privacy`、信箱链接与页脚链接。未取得确认的真实备案号，不填占位号；备案适用性与信息另行核实。 |

Draco 处理压缩网格，需要解码；当前岛屿直接用代码生成几何体，没有待压缩的 glTF
模型下载。继续使用已有几何合批、阴影缓存、像素/帧率预算，避免加入无对应资产的解码器。
参考：[Three.js DRACOLoader](https://threejs.org/docs/pages/DRACOLoader.html)、
[Umami 自托管要求](https://docs.umami.is/docs/install)、[Giscus 配置要求](https://giscus.app/zh-CN)。

## 初始模式与手机交互

`visit-policy.mjs` 集中决定初始视图。明确保存的 `reading` / `3d` 选择优先；
首次访问开启省流量时先看轻量导览。粗指针设备报告内存或核心数不超过 2 时，也先
看导览。未知或未提供的数值不据此判为弱设备。这只是保守提示，不是硬件性能测量。
其他手机仍可直接进入 3D；任何时候都能手动切换，沿用原有 `ly-island-view` 偏好。

触摸设备提示单指旋转、双指缩放、轻点建筑；初始暂停持续漂浮，用户可以明确继续。
静止、隐藏和阅读时沿用原来的按需绘制。触摸事件只将主触点的一次轻点视为进入建筑；
副触点释放或不匹配的 pointerId 不打开内容，保留正常点击、旋转和布置拖动。

## 导览与等待

SVG 导览使用固定构图及当前建筑名称，实际布局仍以 3D 存档为准。五个建筑有键盘
可聚焦链接和辅助名称，下方保留较大的文字入口。它不用 Three.js、图片下载或第三方
资源；存档、积分和公开内容数量不受切换影响。不是新建筑，也不增加悬停内容卡片。

省流量/已选择轻量模式时，配置请求尚未结束也能先使用导览。配置或场景资源较慢时
可以点击「先看轻量导览」，旧请求完成后不会重新切回 3D。首次绘制前保留超时兜底；
导入失败、WebGL 创建失败或上下文丢失时显示导览和文字导航。

只有公开列表成功读取且对应空间没有记录时才显示空内容引导。读取失败保留错误与
重试入口，不能被标成空岛；空工坊仍保留 CivilFlow 与七嘴链接。没有发布种子内容，
没有把草稿计入公开列表，也不生成建设进度或虚构工程成果。

## 验证

- 全部网站脚本检查及 `npm run test:scene`、`npm run build`，无生产数据挂载。
- 策略测试覆盖明确偏好、省流量、未知/无效硬件、触摸文案；指针负例在修复前失败。
- 隔离 Chromium/Firefox/WebKit：五个 SVG 键盘/触摸入口、390/320px、无 3D 下载的
  导览、空内容与读取失败区别、禁用 WebGL、慢配置跳过、无 JS 文章及隐私页。
- Chromium/WebKit：手机 3D 初始暂停、静止无持续绘制、迟到场景不覆盖导览；
  Chromium 另用真实浏览器触摸事件检查旋转、双指缩放与副触点边界。
- 线上仅作 GET/HEAD 验收；真实手机 GPU、输入手感、发热/电耗与 Safari 应用仍需实机
  检查。软件浏览器的窄屏/触摸模拟不作为真机性能证明。
