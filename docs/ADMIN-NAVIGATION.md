# 后台栏目与写作方式

后台按任务组织，现有内容、类型、草稿及 URL 不迁移。

| 导航组 | 栏目 | 放在这里的操作 |
| --- | --- | --- |
| 工作台 | 总览、AI 助手 | 最近工作、新建内容、继续编辑、站主 AI |
| 内容 | 内容管理、分类与系列、图片库 | 统一内容列表、写作、归属和素材 |
| 小岛 | 展示设置、岛屿布置、信箱 | 公众文案、场景位置、来信审核 |
| 管理 | 维护与备份、账号安全、使用指南 | 状态、完整 ZIP、导入/导出、账号安全和帮助 |

内容管理包含「全部、笔记、博客、项目、草稿箱、回收站」六个视图，
不再分别挤占侧栏。原来的 `/admin?view=notes`、`blogs`、`projects`、`drafts`、
`trash` 链接继续可用，并选中「内容管理」与对应子视图。筛选只作用于列表，
不能悄悄改变已有编辑的类型或丢失未保存正文。进入笔记/博客/项目视图时，
完全空白且未修改的新编辑器才跟随选择默认类型。

笔记和博客按用途区别，二者共用写作、草稿、历史与发布机制：

- **笔记：整理知识。** 用于结构知识、工程方法与学习资料。书屋先显示分类书架，
  每个分类是一本书，打开书才显示该分类的笔记列表，正文保留目录、书签、表格与公式。
- **博客：个人记录。** 用于随手想法、近况与随笔。位于岛主空间独立的博客页，
  总览「写一则博客」进入随笔速写，标题可自动补齐；前台是时间动态与简洁阅读。
- **项目：维护工作档案。** 记录职责、阶段和成果，关联相关笔记和博客。

内容页有随时可展开的选择说明。已有内容需要改类型时，在编辑器的类型选择框操作，
明确保存/更新发布后才生效；不是自动重写或建立另一份内容。

总览保留新建与最近工作。备份/发布状态、完整内容包下载与导入、单独 JSON 导出
集中到 `/admin?view=maintenance`，避免日常写作被维护操作淹没。账号仍是同一账号，
两步验证与所有权限边界不变。本轮继续部署 VPS，不接入 Cloudflare。

分类书复用「分类与系列」里的专题（笔记分类），多选分类时同一篇笔记在多个书中出现。
没有自定义分类时保留工程/探索或待分类入口。旧文章的类型和网址不自动改写，详见
[知识书架与岛主博客](KNOWLEDGE-AND-JOURNAL.md)。
