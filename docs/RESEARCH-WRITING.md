# 工程写作与文章分享

正文使用 CommonMark 与表格语法，在后台预览、岛内阅读、独立 `/notes/<slug>` 页面共用服务端渲染。存储中的正文、文章地址及发布状态不变；浏览器后台继续作为编辑入口。

## 写表格和公式

写作工具栏新增「表格」「公式」，点击即可插入可修改的示例：

```markdown
| 参数 | 数值 | 单位 |
| --- | ---: | :---: |
| 跨径 L | 30 | m |
| 荷载 q | 20 | kN/m |

均布荷载为 $q$，跨径为 $L$。

$$
M_{max} = \frac{qL^2}{8}
$$
```

`---:` 右对齐，`:---:` 居中。较宽的表格在自身区域横向滚动。公式用 `$...$` 表示行内、`$$...$$` 表示独立段落；金额里的美元符号可写成 `\$`，代码块和行内代码中的公式符号不转换。

后台继续按编辑位置跟随：点击表格行定位到对应预览行，点击公式源码定位到对应公式块。不完整或不支持的公式显示原文，不会使整篇预览失败。

使用 markdown-it、`@mdit/plugin-tex`、KaTeX 和 sanitize-html，版本锁在 package-lock.json。KaTeX 在服务端生成原生 MathML，不向外部 CDN 请求脚本或字体。隔离浏览器验收使用 Chromium；尚未实测 Safari/Firefox。单公式 4000 字符、单正文最多 100 次公式渲染与 30000 个公式字符，宏展开与尺寸另有限制，超限显示原文。

服务端与岛内浏览器共用 `article-policy.mjs` 白名单：正文不支持原始 HTML、远程图片或危险链接；公式不允许 HTML 扩展、远程资源或可执行链接。MathML 不接受嵌入 HTML/SVG/annotation-xml 或事件属性。上传图片仍沿用私密草稿与公开引用规则。

## 分享与独立阅读

岛内打开文章后，浏览器标题随文章变化；回到岛上恢复首页标题。「复制这页链接」复制同源的 `/notes/<slug>` 永久地址，旁边提供独立文章页入口。独立页面也有返回岛内这篇文章的链接。

独立页面包含文章标题、描述、canonical、Open Graph 和 Twitter 卡片信息；有封面时带公开封面图片。只有公开且未回收的文章有这些页面，草稿无法被分享接口或站点地图公开。第三方平台是否抓取/缓存卡片取决于该平台，未做平台逐项验收。
