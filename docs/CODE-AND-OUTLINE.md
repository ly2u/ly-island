# 代码块与长文目录

代码围栏后的语言名用于高亮，例如 `python`、`bash`、`powershell`、`json`、`yaml`、`ini`、`js`、`ts`、`html`、`css`、`sql`、`c`、`cpp`、`csharp`、`latex`。
编辑器代码按钮旁可以选语言；代码按钮把所选语言写进围栏，选择语言本身不改变文档或触发草稿保存。
未标注或不支持的语言保留纯文本，不猜测语言。现有文章按原Markdown直接渲染，不需要重新发布或重写正文。

## 同一份代码，多处阅读

独立文章、岛内文章、实时编辑预览和访客视角预览使用同一份安全渲染及复制逻辑。
语言标题和复制按钮在pre之外；复制只读取code.textContent，保留制表符、空格、换行和Unicode，
不带语言名/按钮文字/高亮HTML。Markdown统一使用LF换行，不能把Windows换行字节差异视为原文丢失。
点击才写剪贴板；成功有反馈，失败仅选中代码并提示使用系统复制，不能假报成功。
客户端增强可重复初始化并清理监听/计时器，切换文章不会产生重复按钮。

高亮由服务器上的固定版本Highlight.js核心和17个选定语法生成，浏览器只收到已消毒的span和样式，
不加载高亮引擎、CDN或外部资源。类名与语言属性采用有限允许列表，代码永不执行。
单块超过20,000字符、全文代码累计超过50,000字符或代码块超过200个时保留原文，略过超额高亮。
关闭JS仍有语言标签、语法颜色和原生可选择代码；一键复制需要JS和浏览器剪贴板权限。
高亮调用遵循[官方核心API](https://highlightjs.readthedocs.io/en/latest/api.html)。

语法和消毒相关依赖同时更新到markdown-it15.0.3、sanitize-html2.18.2；
修补依据为[Markdown参考定义处理](https://github.com/advisories/GHSA-gfr2-rv44-r23c)
及[丢弃iframe时的递归问题](https://github.com/advisories/GHSA-c9rx-x947-fp3h)，本次npm生产依赖审计为0项。

## 长文目录

目录高度受实际阅读滚动容器限制，有独立滚动条；岛内使用room-scroll，独立文章使用window，
访客预览使用dialog。长目录省去侧栏插画，较矮窗口进一步收起辅助信息，保留可用目录空间。
阅读时高亮当前章节并只滚动目录容器，使当前项可见，不对正文调用scrollIntoView。
只有用户点击目录才滚动正文，并遵循减少动态效果设置。主动滚动目录时保留手动位置，
转回正文阅读后继续跟随；aria-current标记当前章节。监听、帧回调和ResizeObserver随阅读器清理。

源码位置映射仍附着pre，语言标题/复制提示不混进代码块的光标定位；反引号和波浪线围栏都能跟随预览。
验收包括57个代码块/61个标题、末尾高亮、真实剪贴板与拒绝路径、目录独立滚动/当前位置/不带偏正文、
岛内与模态滚动容器、600px矮窗口、390/320px、无JS显示、编辑正文保持与预览跟随。
测试内容全部在隔离副本；线上只做只读检查，不发送模型或Civil请求。
