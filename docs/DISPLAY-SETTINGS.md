# VPS 展示设置与内容类型

当前优先维护 Debian / Docker Compose / Caddy 上的 rqly.com。framework 分支的
Cloudflare 实验独立保留，本轮不部署 Worker、不迁移内容、不修改 Civil 执行连接。

## 管理入口

`/admin?view=display` 的「展示设置」集中维护：

- 岛名与岛屿介绍；站点名称、标志文字、英文副标题、首页主标题与身份介绍。
- 浏览器/分享标题、搜索/分享简介和页脚短句。
- 岛主公开署名、身份签名、侧栏短句、介绍标题与完整 Markdown 介绍（即时预览）。
- 建筑名称/介绍/精选、三处空间内页标题、信箱名称与介绍、成长卡片标题。
- 成长卡片、最近更新、底部快捷导航及首页身份介绍的展示开关。
- 书屋初始视图：分区展示、笔记或博客。
- 最多八个工具：名称、说明、标签、HTTP(S) 地址、显示开关、排序。

「岛屿布置」继续维护布局、光照、阶段、成长目标及装饰。两处共用 `island.json`、
同一份表单和 revision；切换管理栏目保留未保存的输入，点击「保存并展示」才公开。
两个标签页竞争保存会得到 409，不能悄悄覆盖。重新载入和载入默认文案均有确认。
账号口令、认证、SSH、域名、备份计划和网络权限不是展示设置。

无需改代码或重新构建即可更新以上内容；已经打开的公众页面在刷新后读取新设置。
旧 island.json 缺少 presentation 时只在读取时补默认值，不改磁盘或文章。
新字段仍在 schemaVersion 1 的可选 presentation 下，旧程序忽略它；发布回退不需要
还原文章。特别注意：旧版本保存岛屿会丢弃它不认识的新字段，因此回退期间先勿编辑布局。

介绍只经过已有 Markdown 清理器输出；不接受自定义 HTML、CSS、脚本或任意模板。
工具链接不由服务器抓取，没有新增出站请求能力；危险协议、带凭据 URL 和已撤回图片
路径不接受。隐藏工具不出现在公众 API 或页面。介绍中引用的本站图片视为公开引用，
在图片库中受删除保护，随现有备份/可移植内容包中的岛屿配置保留。

## 笔记、博客和项目

它们共用内容存储、草稿、搜索、历史和明确发布边界，不重复保存文章。

- 笔记：短句、摘录、现场线索；简洁速记支持自动标题。书屋里是按时间排列的轻量列表，
  展开后是一列便笺排版。没有硬性限制篇幅，仍可使用 Markdown、表格和公式。
- 博客：整理成篇的主题文章；书架封面、摘要和长文阅读目录/书签。
- 项目：背景、职责、阶段与成果；可以关联笔记和博客。

`/notes?kind=note`、`/notes?kind=blog`、`/notes?kind=project` 都有服务端目录，
独立文章继续使用原来的 `/notes/<slug>`，类型修改不会改变 URL。没有自动改写已有类型。

## 首页的服务端填充

Caddy 继续直接提供哈希资源。首页改为将只读挂载的构建 index.html 交给 sites 填充固定
文案槽位，返回已有 CSP 下的 HTML；不执行模板或新增渲染依赖。文章与 /about 的署名、
公共侧栏和 RSS 使用相同配置。关闭 JS 仍有文字目录、真实工具链接与新首页文案。

上线前应将以下已审查配置安装到 /opt/ly-stack（保留原文件，切勿打印 .env）：

1. 备份；核对新旧 compose.yaml/Caddyfile，只增加 sites 的只读岛屿产物挂载、首页代理
   和旧镜像 404 的静态兜底，其他服务与安全头保持。
2. 安装新 compose.yaml/Caddyfile。`docker compose config -q`；在已有 caddy 容器内
   `caddy validate` 成功后 reload。旧 sites 没有新首页接口，仍自动返回静态岛屿。
3. 从新 main 标签运行新版 `scripts/release.py check` 和 `deploy`。sites 重建时获得只读挂载；
   后续首页填充始终读取发布流程当前安装的 index.html。
4. 验证首页、/about、文章/后台和备份。回退旧镜像仍经 Caddy 的 404 兜底展示旧静态岛屿。

发布检查仍核对所有原始构建文件 SHA-256（index 从 /island/index.html 读取），并另外
确认公开首页引用的资源集合与这个构建一致且全部可读。不是取消原来的版本/回滚检查。
内部 /island-home 直接访问为 noindex，主首页通过 Caddy 不带 noindex。

## 阅读窗口

桌面宽度至少 1100px 时，面板占右侧约三分之二（右侧保留24px边距），左侧保留
三分之一；点击左侧、按 Esc 或关闭按钮返回。3D 对焦使用相同边界，建筑不跟着搬位置。
较窄窗口使用宽面板，手机继续全屏。此调整不改变已保存的岛屿布局。

- `apps/ly-island-preview`：`npm run test:scene`、`npm run build`。
- `python3 scripts/check-release.py` 和已有备份/回执测试。

  隐藏工具、笔记/博客、桌面三分之二与左侧返回、手机宽度及保存前后布局不变。

真实线上只读验收，不重设真实密码、不创建测试文章，不发 AI / Civil 请求。
